# Parjad Minooei - Software Engineer Portfolio 🚀

Welcome to my personal portfolio repository! This project is a full-stack web application designed to showcase my software engineering journey, projects, and technical skills through an immersive, interactive user experience.

## ✨ Key Features

- 🖥️ **Interactive CLI Mode:** A fully functional, retro-style terminal emulator with a mock file system, tab autocompletion, live API fetching, and an interactive email wizard.
- 🎬 **Cinematic Intro:** A 3D, physics-based particle network with hacker-style text decoding and smooth entry animations.
- 🚀 **Full-Stack Architecture:** Built with a React frontend and a robust Node.js/Express backend connected to MongoDB.
- 💫 **Fluid Animations:** Comprehensive page transitions and micro-interactions powered by Framer Motion.
- 📊 **Live Statistics:** Real-time integration with GitHub and LeetCode APIs to display live coding metrics.
- 🌐 **SEO Optimized:** Dynamic meta tags and OpenGraph data for maximum discoverability.

## 🛠️ Tech Stack

**Frontend:**
- React 18 (Vite)
- Tailwind CSS
- Framer Motion
- React Router DOM
- React Helmet Async (SEO)

**Backend:**
- Node.js & Express
- MongoDB & Mongoose
- JSON Web Tokens (JWT) for Admin Auth
- Nodemailer (Contact form routing)

## 🚀 Running Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ParjadM/ParjadM-Portfolio.git
   cd ParjadM-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the `server` directory and add your MongoDB URI, JWT Secret, and SMTP credentials.
   *(Refer to `server/.env.example` if available).*

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   *This uses `npm-run-all` to start both the Vite frontend and the Node backend simultaneously.*

5. **View the Application:**
   Open [http://localhost:5173](http://localhost:5173) in your browser.
